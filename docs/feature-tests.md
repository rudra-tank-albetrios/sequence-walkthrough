# Feature tests

One row per row of the plan's section 10, naming the tests that prove it and an honest status:
`proven`, `partly`, `later: phase N`, or `cannot in a browser: why`. Browser tests live in `e2e/`
and run on Chromium, Firefox, WebKit and a Pixel 7 project (`npm run test:e2e`); unit tests run
with Vitest (`npm run test`). Rows that depend on later phases say so and are finished there.
