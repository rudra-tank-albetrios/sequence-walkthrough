# Feature parity checklist: version 2 → React viewer

Built from `README.md` and `src/body.html`, `src/style.css`, `src/js/*.js` of the version 2 page (plan section 7.2), which stay in git history at commit `398d08e`. Each row is one observable feature; the Test column names the Playwright test(s) in `e2e/` that exercise it, or says why none can. **(old data)** marks features that read storage written by version 2 (keys and shapes in `docs/v2-internals.md`). Element ids and class names are the old ones, given so a test can be written against the old page first and then adapted.

Areas follow the plan: Diagram, Walkthrough, Step details, Views, Personal data, Sharing and files, AI, Other.
